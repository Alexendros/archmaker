# Inventario y hallazgos

- Los siete JSON parsean.
- El schema v5.1 acepta la instancia.
- El schema original produce cinco incompatibilidades frente a la instancia: `single`, `count_gt` y tres arrays de presets.
- `base-devel` está duplicado.
- `cmd`, hooks y `pacstrap` se conservan solo como evidencia no ejecutable.
- Los prototipos contienen recursos CDN y fuentes remotas.
- Los datos técnicos requieren verificación primaria antes de convertirse en catálogo.
