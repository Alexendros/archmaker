# Plan de evidencia

## Prioridad P0

- ArchWiki y archinstall: flujo, profiles y limitaciones.
- Repos oficiales/AUR: existencia, arquitectura, fuente y freshness de cada paquete.
- Tauri 2: permissions, capabilities, CSP, updater y scopes.
- JSON Schema 2020-12 y canonical JSON.
- WCAG 2.2 y WAI-ARIA APG.
- NIST SSDF, SLSA y Sigstore.

## Registro por afirmación

`claimId`, texto, fuente primaria, URL, versión/commit, fecha de captura, target afectado, verificador, estado y fecha de revisión.

## Regla académica

Distinguir hechos verificados, hipótesis, decisiones de producto y recomendaciones. Las afirmaciones mutables no se copian de blogs cuando existe fuente primaria.
