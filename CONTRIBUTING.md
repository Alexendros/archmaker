# Contribuir

- Abrir issue trazado a FR/NFR.
- Backlog de issues: `docs/10-delivery/next-issues.md` (no abrir issues en GitHub mientras el gate `planning-v1` sea No-Go).
- Decisiones estructurales mediante ADR.
- Commits pequeños y Conventional Commits.
- PR con aceptación, pruebas, seguridad, accesibilidad y documentación.
- No editar `reference/v5.1/`.
- No añadir runtime CDN, shell, hooks ejecutables ni secretos.
